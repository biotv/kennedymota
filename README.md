# Kennedy Mota - Perfil Profissional

Perfil profissional estatico de Kennedy Mota, criado a partir das informacoes de `sinopse.txt` e da imagem `kennedy.png`.

## Arquivos

- `index.html`: pagina principal do perfil.
- `styles.css`: estilos responsivos da pagina.
- `kennedy.png`: imagem usada como foto de perfil.
- `background.png`: imagem usada como fundo visual da pagina.
- `sinopse.txt`: texto-base com informacoes profissionais e academicas.
